# Product overview

Lab DAO is an independent membership + proposal office + voting urn on **Redbelly Testnet**.

## Goals

1. **One roof** - join, file, coach with High Council, and vote in one place (not Discord drafts + Snapshot as the only path).
2. **Identity, not address** - one membership mark, one ballot; link wallets instead of a second Join.
3. **Hybrid urn** - ballots stay on the platform; the chain gets the result, not a public "who voted how" roll by default.
4. **Honest limits** - no promise of one network KYC = one vote; gates (tenure, XP, Discord, allowlist) tighten where stakes are high.

## Surfaces

- **Join / Profile** - CAT check, Identity, link wallets, optional Discord
- **Proposals** - draft → HC queue → private thread → public discussion → lab vote
- **How** - public map for members and High Council (no PIN)
- **Resources** - living docs and on-chain addresses
- **Archive** - closed lab votes (+ optional Snapshot.org history, read-only)

## What this public repo is not

- Not the application source
- Not deployment or ops documentation
- Not a full private API / HC runbook

Those stay in the private engineering repository.
